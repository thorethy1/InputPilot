Three simple steps

How it works

You need the supported board, a USB-C data cable, and about two minutes.

  1. 01

    Connect the board

    Connect the ESP32-S3-Zero directly to your computer with a USB-C data cable.

  2. 02

    Enter download mode

    Hold BOOT, briefly press RESET, then release BOOT.

    My board has no RESET button

    Unplug USB, hold BOOT, reconnect USB, and then release BOOT.

  3. 03

    Install

    Click “Install firmware” above, select the ESP32-S3 port, and confirm. When installation finishes, unplug the board and reconnect it once.

After flashing

Pair securely with the app

Open InputPilot on your iPhone and choose “Add Device → Set Up Securely”. Install future firmware updates conveniently and securely through the app—the web flasher is intended for initial installation and recovery.

Good to know

Browser & troubleshooting

Which browser?

Use Chrome or Edge on Windows, macOS, or Linux. Safari, Firefox, and browsers on iPhone or iPad do not support Web Serial.

No device listed?

Check the data cable, close serial monitors, and enter download mode again. Charge-only cables do not work.

Which firmware?

This page publishes only InitialFirmware.bin from the latest stable GitHub release. Beta releases are ignored.
