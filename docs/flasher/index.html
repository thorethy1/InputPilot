S3

Bereit zum Installieren

Waveshare ESP32-S3-Zero

ESP32-S3FH4R2 · 4 MB Flash

Der Web-Flasher benötigt Chrome oder Edge auf einem Desktop-Computer.
Der serielle Zugriff ist hier blockiert. Öffne diese Seite direkt über HTTPS.

Die Installation löscht vorhandene Einstellungen auf dem Board.

In drei Schritten

So funktioniert’s

Du brauchst das unterstützte Board, ein USB-C-Datenkabel und etwa zwei Minuten.

  1. 01

    Board verbinden

    Verbinde den ESP32-S3-Zero mit einem USB-C-Datenkabel direkt mit deinem Computer.

  2. 02

    Download-Modus starten

    Halte BOOT gedrückt, drücke kurz RESET und lasse danach BOOT los.

    Mein Board hat keinen RESET-Taster

    USB abziehen, BOOT gedrückt halten, USB wieder einstecken und anschließend BOOT loslassen.

  3. 03

    Installieren

    Klicke oben auf „Firmware installieren“, wähle den ESP32-S3-Port und bestätige die Installation. Ziehe das Board danach einmal ab und stecke es wieder ein.

Nach dem Flashen

Sicher mit der App koppeln

Öffne InputPilot auf deinem iPhone und wähle „Gerät hinzufügen → Sicher einrichten“. Zukünftige Firmware-Updates installierst du bequem und authentifiziert über die App – dieser Web-Flasher ist für die Erstinstallation und Wiederherstellung gedacht.

Gut zu wissen

Browser & Fehlerbehebung

Welcher Browser?

Nutze Chrome oder Edge unter Windows, macOS oder Linux. Safari, Firefox und Browser auf iPhone/iPad unterstützen Web Serial nicht.

Kein Gerät sichtbar?

Prüfe das Datenkabel, schließe serielle Monitore und wiederhole den Download-Modus. Lade-Only-Kabel funktionieren nicht.

Welche Firmware?

Die Seite veröffentlicht ausschließlich InitialFirmware.bin aus dem neuesten stabilen GitHub Release. Beta-Releases werden ignoriert.
